# Source data

Download **Online Retail.xlsx** from the [UCI Online Retail dataset page](https://archive.ics.uci.edu/dataset/352/online+retail) and place it in this directory, or run `python scripts/download_data.py` from the repository root.

The workbook is excluded from version control. The notebook reads `data/Online Retail.xlsx` without modifying it.

- Source: Chen, D. (2015). Online Retail. UCI Machine Learning Repository.
- DOI: https://doi.org/10.24432/C5BW33
- License: https://creativecommons.org/licenses/by/4.0/
- Expected original shape: 541,909 rows and 8 columns.
- SHA-256 of the workbook used in this project:

```text
43465a06f2ccf7c8b5bd2892bc7defb52f97487934fe93b16ae4c3936424676d
```

A checksum mismatch means the bytes differ from the workbook used for this analysis. Confirm the source/version before assuming the same results.
